# 幸福小Molly：分阶段开发与验收计划

## 总则

- 每阶段先确认对应文档，再开始该阶段的代码。
- 一个阶段只引入本阶段必需的数据表和界面，不提前实现下一阶段业务。
- 每阶段完成后更新 `HANDOFF.md`，记录实际验证和下一步。

## 阶段 1：基础与云端可信保存

### 范围

- 建立 React + TypeScript 项目骨架。
- 接入认证、用户资料、数据库迁移和 RLS。
- 建立通用保存状态、错误状态和数据服务层。

### 不包含

- 正式的日程、饮食、补剂业务页面。

### 验收

- 手机和电脑可登录同一账户。
- 新建测试记录后刷新仍存在，另一设备可见。
- 断网或服务端失败时显示“保存失败”，不得显示“已保存”。

## 阶段 2：日期引擎与周视图

### 范围

- 周一至周日固定周视图。
- 今天、明天、未来日期和历史只读规则。
- 工作日/休息日默认判断及人工覆盖，含确认框。

### 不包含

- 三餐、补剂、健身等具体规划内容。

### 验收

- 周末与工作日默认正确。
- 两种人工切换文案和内容模式正确。
- 历史日期无法通过前端或接口修改。

## 阶段 3：工作日规划闭环

### 范围

- 自定义事项与时间线。
- 衣服准备、三餐、晨间事项、健身安排、准备进度。
- 底部编辑面板、复制昨天、5/5 完成反馈。

### 不包含

- 周末专属家务、选项管理页面。

### 验收

- 可完成一份工作日明日计划。
- 五项准备勾选和进度始终一致。
- 复制后内容正确、完成状态为空。
- 手机浏览器上面板与长内容无溢出。

## 阶段 4：补剂、休息日与选项管理

### 范围

- 固定补剂模板与每日实例、早中晚执行勾选。
- 休息日拖地、洗衣和自由规划。
- 食物、补剂、健身选项管理。

### 验收

- 修改补剂或食物选项不会改变历史计划。
- 周末默认有拖地和洗衣；临时不上班不自动带入。
- 新增、停用选项正确影响未来计划。

## 阶段 5：回归、可维护性与发布准备

### 范围

- 完整手机、桌面和跨设备回归。
- 可访问性、错误信息、加载状态与数据迁移检查。
- 清理死代码、补齐测试和运行说明。

### 验收

- 登录、规划、保存、刷新、换设备、断网失败、重试和历史查看全部通过。
- 数据库迁移可从空库完整执行。
- 目录没有跨模块直接访问数据库的代码。

## 阶段准入

只有当前阶段的验收完成、已记录在 `HANDOFF.md` 后，才启动下一阶段。
