# 本地数据库说明

本项目的业务写入落点仍然是浏览器 IndexedDB。本地 PostgreSQL 只用于仿真线上
Supabase 数据库，便于开发时检查持久化、表结构、RLS、触发器和 RPC。

## 前置条件

需要安装 PostgreSQL 16 或更高版本。默认使用：

```text
C:\Program Files\PostgreSQL\16\bin
```

如果安装位置不同，可以设置 `MOLLY_PG_BIN` 指向包含 `initdb`、`pg_ctl`、
`pg_isready`、`psql`、`postgres` 的 `bin` 目录。

## 常用命令

```bash
npm run db:local:init
npm run db:local:status
npm run db:local:start
npm run db:local:stop
npm run db:local:reset
```

首次 `init` 会创建项目根目录下的 `.local-supabase/data`，执行
`scripts/lib/supabase-shim.sql` 和 `database/migrations/` 中的全部迁移。
之后停止和重新启动不会丢失数据。

默认连接参数：

```text
host=127.0.0.1
port=55432
database=molly
user=molly
```

可以通过 `MOLLY_LOCAL_PG_PORT`、`MOLLY_LOCAL_PG_DB`、`MOLLY_LOCAL_PG_USER`
和 `MOLLY_LOCAL_DB_DIR` 覆盖默认值。

## 查询数据库

`psql` 命令会自动启动数据库：

```bash
npm run db:local:psql -- -c "select current_database(), now();"
npm run db:local:psql -- -c "\dt public.*"
```

## 重置

`reset` 会先停止数据库，把旧数据目录复制到
`.local-supabase/backups/`，再按当前迁移重新创建数据库。因此修改迁移后可以
用它重新得到一份干净的本地数据库。

本地数据库不会自动成为前端的 Supabase API 地址。当前前端仍通过真实 Supabase
的 URL 和 anon key 访问云端；没有配置时，前端继续只使用 IndexedDB。
