# 幸福小Molly：页面与交互规范

## 视觉方向

- 移动端优先，内容区以白色为主。
- 页面底色与强调元素采用参考图的浅粉至玫红渐变。
- 完成勾选、进度条和主要确认按钮使用渐变；文字与白色内容区保持足够对比度。
- 不使用通知铃铛或倒计时，产品语气安静、直接。

## 应用导航

底部固定三个入口：

1. 今日：默认入口，包含“执行今天／准备明天”。
2. 本周：固定显示本周周一至周日。
3. 选项：管理食物、固定补剂、健身项目和账号同步。

## 今日页

### 顶部

- 显示“幸福小Molly”、当前日期、云端保存状态。
- 分段控制：`执行今天`、`准备明天`。
- 两个状态各自读写对应日期；切换不会覆盖另一日内容。

### 日期模式

- 点击模式行才打开确认框，不在点击后立即改变。
- 工作日确认改为休息日时：文案为“恭喜幸福小Molly，今天不上班”。
- 休息日确认改为工作日时：文案为“幸福小Molly，今天要上班哦”。
- 确认框需解释切换会改变可见内容；取消不改变数据。

### 准备区

工作日显示 5 个带勾选的行：衣服、三餐、补剂、晨间事项、健身安排。

- 左侧勾选框只表示“此项已准备”。
- 点整行或右侧箭头打开对应底部编辑面板；不可用“编辑”代替勾选。
- 每行可在下一行显示一行浅色摘要，例如三餐组合或晨间内容。
- 进度严格依据五个勾选框计算。达到 5/5 时显示“美好的一天结束啦，迎接下一天！”。

### 自定义时间线

- 按时间升序显示事项，每项显示时间、名称、备注和完成勾选。
- 加号打开“添加事项”底部面板。
- 编辑、删除必须在当前事项的编辑面板中完成；删除需确认。

### 执行区

- 执行今天时，显示各项实际完成勾选，包括早、中、晚补剂。
- 计划内容与完成状态保持区分：例如“三餐已安排”不等于“三餐已吃”。

## 底部编辑面板

- 从屏幕底部上推，保存或取消后回到原位置与原滚动位置。
- 面板标题要表明正在编辑的对象，如“编辑三餐”。
- 三餐：按早餐、午餐、晚餐分组，多选常用食物，填写备注。
- 补剂：按早、中、晚展示每日实例；可增删和调整时段。
- 晨间事项：显示固定时段 `5:00-6:30`，输入一段当天计划。
- 健身：先选择“健身”或“不健身”；选择健身时多选项目并填写备注。
- 所有保存操作显示成功或失败状态，不自动假定已同步。

## 本周页

- 顶部显示周一至周日的固定七天条。
- 每天显示状态：未规划、待准备、执行中、已完成。
- 点击任意日期直接进入该日期完整页。
- 过去日期打开后为只读状态，不显示编辑或复制入口。

## 选项页

- 常用食物：新增、重命名、排序、停用；停用项不再出现在新计划中。
- 固定补剂：名称、早/中/晚、启用状态。
- 健身项目与动作：新增、重命名、排序、停用。
- 账号与同步：当前登录状态、最近同步时间、同步失败时的重试操作。

## 关键确认与空状态

- 复制昨天：目标日期已有计划时，说明将覆盖哪些计划内容；确认后不复制完成状态。
- 删除事项：二次确认。
- 未来空日期：引导用户“准备这一天”，但不强制填写。
- 历史日期：显示“历史计划仅供查看”。
