# 幸福小 Molly：业务响应图说明

业务响应图见 [40-业务响应图.svg](./40-业务响应图.svg)。

## 阅读方式

图按四条泳道从上到下阅读：

1. **用户动作**：完成事项、编辑计划、切换工作日/休息日，以及后续可扩展的备份、账号和云端动作。
2. **业务与本地数据**：业务服务执行 IndexedDB 写入。成功和失败在这里分叉；只有写入成功才发布成功类反馈事件。
3. **反馈编排**：`FeedbackBus` 负责去重和分发，`FeedbackPolicy` 负责优先级、日期过滤和互斥，`FeedbackHost` 负责表现状态与时序。
4. **用户可见响应**：普通完成提示、礼花与宠物回应、保存失败播报，或被规则丢弃/暂不打断的反馈。

## 关键业务规则

- **保存失败不庆祝**：失败只发布 `save-failed`，保留原有错误栏与重试入口。
- **庆祝优先**：工作日转休息日的庆祝优先级高于普通完成提示；礼花播放期间普通提示不打断。
- **上下文有效**：切换日期、打开选项面板或事件日期不匹配时，反馈不进入当前展示层。
- **本地优先**：本地保存成功只说明 IndexedDB 写入完成，不能替代云端同步状态。
- **表现与业务解耦**：动画、宠物和提示只消费事件，不写入业务数据。
