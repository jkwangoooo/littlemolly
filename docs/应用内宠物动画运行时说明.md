# 应用内宠物动画运行时说明

当前应用恢复为第一版稳定的 `FloatingPet` 实现。此前的 Pets 逻辑复刻已撤回，资源仍使用本项目自己的透明 PNG 帧目录。

## 当前运行时契约

- 宠物组件：`src/shared/components/FloatingPet.tsx`
- 资源根目录：`public/pets/ember-monkey-v1/`
- 运行时点击区域：88 × 88 px
- 当前运行帧：`walk12/行走-01.png` 至 `行走-12.png`
- 左右方向：同一套左行帧，右向用 `scaleX(-1)` 镜像

## 已复刻的逻辑

- 第一版状态：待机、眨眼、拖动行走、释放回弹、点击反馈
- 行走使用 12 帧资源，每帧约 180ms；右向使用水平镜像
- pointer capture、pointercancel、窗口失焦清理拖动状态
- 视口边界与 visualViewport 安全区域约束
- 宠物位置仍通过 `onPositionChange` 提供给现有气泡系统

## 与 Pets 插件的关系

ChatGPT Pets v2 的标准图集是 8 列 × 11 行，cell 为 192 × 208，共包含 idle、running、waving、jumping、failed、waiting、running、review 和 16 个朝向。当前应用暂不加载该 atlas，保持第一版按状态拆分的 PNG 目录和 88px 悬浮宠物布局。

后续若再次尝试 Pets v2 atlas，应单独设计适配层，不要影响当前第一版组件。

## 质量备注

当前 12 帧行走图来自用户提供的 RGBA 图集，原 alpha 已保留；接触表显示图集个别格存在轻微跨格残片，因此这套资源适合作为应用内原型预览。正式发布前建议修复源图集后重新生成 `walk12` 目录。
